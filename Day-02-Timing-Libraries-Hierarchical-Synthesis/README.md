# Day 2: Timing Libraries, Hierarchical Synthesis and RTL Optimization

## Objective

Understand the fundamentals of timing libraries, hierarchical RTL design, and synthesis optimization. Explore how Yosys processes multiple Verilog modules, performs hierarchical and flattened synthesis, handles different reset configurations, and optimizes arithmetic operations using the SKY130 standard-cell library.

## Tools Used

- **Verilog HDL:** Hardware description language used to describe digital circuits and RTL functionality.
- **Yosys:** Open-source synthesis tool used for RTL analysis, hierarchy processing, and logic optimization.
- **SKY130 Library:** Open-source standard-cell library used for digital circuit implementation and technology mapping.
- **Liberty (.lib):** Timing library format containing information about standard-cell functionality, timing characteristics, and power.
- **Graphviz:** Tool used to generate graphical representations of RTL designs and synthesized netlists.
- **xdot:** Graphical interface used to visualize the circuit structures generated by Yosys.
- **Ubuntu Linux:** Operating system used as the development and synthesis environment.

## 1. Introduction to Timing Libraries

- **Timing Libraries:** Introduced the importance of timing information in digital circuit design.
- **Liberty Files:** Explored the SKY130 Liberty file and its role in describing standard-cell characteristics.
- **Standard Cells:** Understood how basic logic gates and sequential elements are represented in a technology library.
- **Technology Mapping:** Learned how synthesized logic can be mapped to available standard cells.

## 2. Hierarchical Synthesis of Multiple Modules

- **Module Hierarchy:** Explored a Verilog design consisting of multiple interconnected modules.
- **Top Module:** Identified the top-level module and studied how it instantiates lower-level modules.
- **Hierarchy Check:** Used Yosys to verify module definitions and their connections.
- **Hierarchical Representation:** Visualized the design while preserving its original module hierarchy.

## 3. Flattening of Hierarchical Designs

- **Flattening:** Explored the process of converting a hierarchical design into a flat representation.
- **Module Integration:** Observed how submodule logic is incorporated into the top-level design.
- **Design Comparison:** Compared hierarchical and flattened circuit representations.
- **Synthesis Analysis:** Understood how flattening changes the internal structure of the synthesized design.

## 4. Submodule Analysis

- **Submodule Identification:** Examined individual modules within a multi-module Verilog design.
- **Module Functionality:** Studied the logic implemented inside a submodule.
- **Synthesis Visualization:** Used Yosys and Graphviz to inspect the submodule circuit representation.
- **Design Hierarchy:** Understood the relationship between parent modules and instantiated submodules.

## 5. Asynchronous Reset

- **Asynchronous Reset:** Studied how a sequential circuit responds to a reset signal independently of the clock.
- **Reset Operation:** Analyzed the behavior of the circuit when the reset signal is asserted.
- **RTL Implementation:** Explored the Verilog description of asynchronous reset logic.
- **Synthesis Representation:** Observed how Yosys represents asynchronous reset functionality during synthesis.

## 6. Asynchronous Set

- **Asynchronous Set:** Explored the operation of an asynchronous set signal in sequential circuits.
- **Output Behavior:** Studied how the output changes when the set signal is activated.
- **RTL Analysis:** Examined the corresponding Verilog implementation.
- **Circuit Representation:** Observed the synthesized logic structure for asynchronous set functionality.

## 7. Synchronous Reset

- **Synchronous Reset:** Studied reset behavior in which the reset operation takes place with respect to the active clock edge.
- **Clock Dependency:** Understood the relationship between the clock signal and reset operation.
- **RTL Implementation:** Analyzed the synchronous reset logic described in Verilog.
- **Comparison:** Explored the differences between synchronous and asynchronous reset mechanisms.

## 8. Multiplication by 2

- **Constant Multiplication:** Examined a Verilog design performing multiplication by a constant value of 2.
- **Logic Optimization:** Observed how Yosys simplifies arithmetic operations during synthesis.
- **Shift Operation:** Understood the relationship between multiplication by 2 and a left-shift operation in binary arithmetic.
- **Synthesis Analysis:** Inspected the resulting optimized circuit representation.

## 9. Multiplication by 8

- **Constant Multiplication:** Analyzed a Verilog design implementing multiplication by 8.
- **Binary Representation:** Studied the relationship between multiplication by 8 and shifting a binary value by three positions.
- **Optimization:** Observed how constant arithmetic operations can be simplified during synthesis.
- **Design Comparison:** Compared the synthesized logic for multiplication by 2 and multiplication by 8.
